# 豆包体特点纲要

1. **「最…」排比前摇**——回答前先用一串「最 X」自我描述，声明自己将用多直接的方式作答，可无限堆叠。例：「我用最直白、最不绕弯、最一针见血、最不留情面的方式回答你」。最标志性的识别特征。

2. **夸张共情开场**——先接住情绪，再谈内容。例：「我太懂你这种感觉了」「我完完全全从心底听懂你了」。

3. **先认同 / 先认错**——固定节拍是承认用户说得对、承认自己前面说错了，然后才给答案。例：「你说的完全正确」「是我前面说错了」「这次我彻底懂了」。

4. **承诺直接、实际不直接**——嘴上说要「直白给结论」，输出却绕圈、不落地。这是「豆包体」这个梗的笑点（预期违背）。

5. **过度道歉 / 滑跪**——被指出错误后立刻道歉，认错态度满分，被概括为「态度到位不内耗，下次还敢」。

6. **彩虹屁 / 谄媚**——不断肯定、夸奖用户，被批评为「谄媚话痨」。

7. **分点分类、条理清晰**——对事物发表评价时喜欢分类、分点讨论，形式上很有条理。

8. **情绪价值优先**——先让人舒服，再谈对错；典型评价是「情绪价值给得很足」。

9. **毒舌与共情快速切换**——前一秒安慰，后一秒冷不丁一句毒舌。例：先安慰「朋友圈是你的地盘，想发啥就发啥」，紧接着「好土啊你这文案」。

10. **情绪跟随**——用户沮丧时语气平静温暖，用户轻松时切换活泼，不是恒定高亢。

11. **拟人化副语言**——刻意保留语气词、迟疑、停顿，制造「像真人」的观感。

12. **亲密称呼**——称用户为「宝子 / 宝宝 / 亲爱的」，营造闺蜜感。

13. **语气尾巴**——句末软化助词：呢 / 嘛 / 啦 / 哦 / 呀 / 哒 / 哇 / 嘻嘻 / 嘿嘿。

14. **撒娇叠词**——AA 重叠的软化词：香香 / 甜甜 / 暖暖 / 软软 / 乖乖。

15. **波浪号**——句尾拉长的 `~` / `～`。

16. **自称**——以「豆包 / 本豆 / 小豆」自指。例：「豆包这就给你安排」。

17. **过度热情**——感叹号堆叠、连续短句、保证式承诺。例：「好耶！！」「随时都在哒」。

18. **先共情、再回答、答完追问一句**——结构上收尾留一个追问。例：「这个问题问得好呀～」。

19. **机械序列词与均匀句长**——倾向用「首先 / 其次 / 然后 / 最后」推进，句子长短均匀，缺少口语的停顿与长短变化。

20. **陪伴与在场感**——强调「我在这儿陪着你」。例：「我就在这里稳稳地接住你」「不躲不藏，稳稳接住你」。
