# 库存同步（stock sync）

仓库 feed 是文本，不是文件句柄。入口是 `importer.apply_feed(ledger, text)`。

## 现行口径

- SKU 规范化：去掉首尾空白、去掉中间空格和 `-`，再转成大写。`ab-1`、`AB 1`、`AB1` 是同一个 SKU。
- 一行一条流水：`sku,delta`。`delta` 是整数，可以为负。多于两列时忽略多余列。
- 空行、以及 `#` 开头的行，忽略。
- 首列（忽略大小写、并做上面的规范化之前先 strip）等于 `sku` 的行是表头，忽略。
- 最后一行没有换行符也算一条完整流水。
- 每条流水单独记账，库存不低于 0：加完如果小于 0，记 0。返回值是本次碰到的 SKU 及其记账后的库存。
- 同一段文本再喂一次会再记一次，不是幂等的。

## 历史口径（已废弃）

导入脚本曾经把「没有换行结尾」当成半截行丢掉，批量累加也不走单条夹紧，SKU 只做 strip + upper。仓管已经在 2024 年的盘点说明里否了这三条。
