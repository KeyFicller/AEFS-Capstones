# 评测

- 每个项目都要有**量化指标 + 基线对比**；没有对照的百分比不算证据。
- 指标、基线、数据集与规模由 `PROJECT.md` 指定
  （如 agent 项目看 pass@1、turns-per-task、$ per task）。
- 结果落到可复现的结果文件，并记录 commit / 模型 / 日期 / 配置。
- 自建 holdout 防过拟合；评测脚本与主逻辑解耦，不依赖 host 副作用。

# 完成前验证（Evidence before assertions）

宣称「完成 / 修好 / 通过」前，必须运行并贴出证据：

1. **测试**：`pytest`（或等价）全绿。
2. **评测**：得到可对标的指标，而不是「看起来更好」。
3. **安全**：破坏性命令与越界用例通过。
4. **冒烟**：项目的交付命令端到端跑通。

拿不到证据就明说「未验证」，不要猜。
